# 사이트 설계도(PRD) — 탱탱불족발 용호점

작성일: 2026-11-18 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
시장에서 족발과 감자탕을 메인으로 저렴하게 팔고(추가 메뉴도 있음), 동네 손님에게 포장 예약을 받는 가게.

## 2. 손님
- 누가: 근처 동네 주민 (집에서 먹으려고 포장해 가는 손님)
- 어디서 알고 오나:
  1. 네이버 지도·검색
  2. 배달의민족·쿠팡이츠 앱
  3. 시장 방문객

## 3. 손님이 궁금한 것 (예약하기 전에)
1. 메뉴와 가격 (족발·감자탕·추가 메뉴)
2. 픽업 가능 시간
3. 양·구성 (몇 인분인지, 무엇이 같이 나오는지)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 음식·가게 사진 (사장님이 가진 실제 사진만 쓴다)
- 만드는 방식 (사장님이 말한 내용 그대로만 적는다 — 내용은 (미정))
- 후기: 네이버 지도·배달앱에 실제 리뷰가 있음. 사이트에 옮길 때는 실제 리뷰 원문만 쓰고, 지금은 자리만 둔다

## 5. 누르게 할 버튼 하나
- 버튼 이름: 포장 예약하기
- 누르면: 예약 폼 (같은 페이지 아래로 이동)

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 한 문장 + 대표 음식 사진 + "포장 예약하기" 버튼
2. 메뉴와 가격 — 족발·감자탕을 크게, 추가 메뉴는 아래 목록으로. 메뉴마다 양·구성(몇 인분, 같이 나오는 것) 함께 표시
3. 픽업 안내 — 픽업 가능 시간, 쉬는 날, 시장 위치(지도 링크)
4. 우리 가게는 이렇게 만들어요 — 만드는 방식 + 가게 사진
5. 후기 자리 (실제 리뷰가 정리되면 넣음, 지금은 비워 둠)
6. 예약 폼

## 7. 예약 폼에서 받을 것
- 이름, 연락처
- 주문 메뉴·크기(小/大)·수량
- 픽업 날짜·시간 — 일요일은 고를 수 없게, 시간은 13시부터 영업 종료 전까지만
- 개인정보 수집·이용 동의 (필수)
- 제출 후 안내 문구: "예약이 접수됐어요. 가게에서 확인 전화를 드리면 예약이 확정돼요." (확정 방식은 사장님 확인 필요)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가게 이름: 탱탱불족발 용호점
- 가격:
  - 족발 小 10,000원 · 족발 大 15,000원
  - 감자탕 小 6,000원 · 감자탕 大 10,000원
  - 추가 메뉴: (미정)
- 양·구성: (미정) — 小·大가 각각 몇 인분인지, 같이 나오는 것
- 영업시간: 매일 12시 ~ 20시, 매주 일요일 휴무
- 픽업 가능 시간: 매일 13시부터 (일요일 제외) — 마지막 픽업 시각은 (미정, 영업 종료 20시 기준으로 확인 필요)
- 위치: (미정) — 시장 이름·가게 주소
- 연락 방법: 010-7205-5570 (사이트에 공개됨)
- 비어 있는 칸은 지어내지 않고 사이트에 "준비 중"으로 둔다.

## 9. 이번에 넣지 않을 것
- 온라인 결제 (값은 픽업할 때 가게에서)
- 회원가입·로그인
- 배달 주문 (배달은 기존 배달의민족·쿠팡이츠 그대로)
- 예약 알림 문자·메일
- 사진 올리기 기능

## 10. 첫 화면 한 문장 후보
1. 시장 족발·감자탕, 미리 예약하고 따뜻하게 찾아가세요
2. 기다리지 말고 포장 예약하세요 — 시장 족발·감자탕
3. 오늘 저녁은 족발·감자탕, 픽업 시간만 정해 주세요

## 11. 다음에 할 것
- 8번 남은 칸 채우기: 추가 메뉴·가격, 小·大 양(몇 인분), 마지막 픽업 시각, 시장 이름·주소 — 메뉴판 사진을 주면 그대로 옮김
- 네이버 지도·배달앱 실제 리뷰 중 몇 개를 골라 후기 자리에 넣기
- 배달의민족·쿠팡이츠 가게 링크 버튼 (배달 원하는 손님용)
- 네이버 지도 가게 정보에 사이트 주소 등록
- 예약 들어오면 사장님 폰으로 알림

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 (시장 밥집 같은 정감, 든든하고 푸짐한 느낌) · 참고 디자인: 없음 — 클로드가 정함
- 화면 기준: 폰 화면 우선 (손님 대부분이 지도·배달앱에서 폰으로 들어옴)
- 예약 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin (예약 목록·상태: 새 예약 → 확인 전화함 → 픽업 완료)
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 예약 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
